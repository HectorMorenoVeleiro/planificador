## Inicializar el proyecto ##
```
npm init
```
## Descargar una dependencia (vite) ##
```
npm i -D vite
```
## Descargar una dependencia de producción ##
```
npm run dayjs
```
## Probar la app en modo local (desarrollo) ##
```
npm run dev
```
## Construir la app ##
```
npm run build
```

## Arrancar la aplicación ##
```
npm run preview
```
